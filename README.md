# 🌐 Mahi Patel — Personal Portfolio

> **Live Portfolio:** [patelmai48.github.io/portfolio](https://patelmai48.github.io/portfolio) *(once GitHub Pages is enabled)*

A modern, responsive personal portfolio website built with pure **HTML, CSS & JavaScript** — showcasing my skills, projects, experience, education, and certifications.

---

## ✨ Features

- 🌙 **Dark / Light Mode** toggle
- 📱 **Fully Responsive** — works on mobile, tablet & desktop
- 🎨 **Smooth animations** & gradient UI
- 📄 **Resume download** section
- 🏆 **Certificates** showcase
- 📬 **Contact** section

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure & Semantic Markup |
| CSS3 | Styling, Animations, Responsive Design |
| JavaScript | Interactivity, Theme Toggle |
